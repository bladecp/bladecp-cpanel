# Security Policy

## Supported versions

Security fixes are evaluated for the latest public release of BladeCP cPanel
Migrator. Versions before 1.0.0 are pre-releases and may be updated or
superseded as part of the normal release process.

## Reporting a vulnerability

Please report suspected vulnerabilities privately by email:

<dev@bladecp.com>

Include enough information for us to reproduce and assess the issue, such as:

- A clear description of the impact.
- Affected plugin version, cPanel & WHM version and operating system.
- Reproduction steps or a minimal proof of concept.
- Any relevant logs, with API keys, passwords, account names, server addresses
  and other sensitive data removed.

Do not open a public GitHub issue, publish exploit details, or share a proof of
concept that could expose users while the issue is being assessed.

## What happens next

We will acknowledge the report, assess its impact, and coordinate an
appropriate fix and disclosure. We do not publish a fixed response-time
commitment. Please allow time for investigation and, where needed, for
partners to apply a release safely.

## Scope

This policy covers the BladeCP cPanel Migrator plugin distributed from
[`bladecp/bladecp-cpanel`](https://github.com/bladecp/bladecp-cpanel): the WHM
plugin, its cron worker, the cPanel app, its cPanel API module and AdminBin, the
installer and the uninstaller. For issues in third-party software, including
cPanel & WHM itself, please contact the relevant vendor as well.
